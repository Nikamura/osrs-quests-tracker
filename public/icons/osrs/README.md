# OSRS interface icons

Game interface and item images by Jagex, sourced from the OSRS Wiki. Used under the Jagex Fan Content Policy, as credited in the site footer.

Each PNG was downloaded from `https://oldschool.runescape.wiki/images/<filename>`. File descriptions and provenance are at `https://oldschool.runescape.wiki/w/File:<filename>`. Filenames are preserved.

These small assets are served locally to keep navigation independent of the Wiki image server.

Boss and activity artwork is resized to a maximum of 64 pixels for compact, locally served table icons. Entity mappings live in `public/js/app.js`; unknown entities use the combat category icon.
